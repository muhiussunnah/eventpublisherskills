## Answer for the CEO — the biggest sources for temporary family events (whole Sweden)

1. **Kommun lov pages + kommun calendars with a Barn/Familj filter** — in every region the single biggest source (e.g. Göteborgs Stad kalendarium Barn 2 405 activities, höstlov filter 446; Linköping 236 / 107 family; Jönköping 167 family + höstlov 111; Mölndal 273; Uddevalla 121). Re-find the lov URLs before every holiday.
2. **Visit/destination calendars with a family category** — Visit Norrköping (~165), Destination Halmstad (~100), Visit Blekinge (90, per-kommun filter), Visit Kristianstad (86), vimmerby.com (418 events), Visit Gotland (329 / ~47 kids), Upplev Norduppland (~450 / ~95 family).
3. **Regional library platforms** (Axiell Arena: Götabiblioteken, Knallebiblioteken, Biblioteken i Fyrstad, Ranrike, Bibliotek SSO, Snokabiblioteken …) — one calendar for many kommuner, filter per library with `#/?location=…&targetAudience=Barn…` (Göteborgs bibliotek barn 310).
4. **Svenska kyrkan** — huge volume of babysång/öppen förskola/barnkör (Hässleholm ~94, Örkelljunga ~70, Partille ~200); the calendar is JS-only, use `svenskakyrkan.se/kalender?type=owner&id=…` links.
5. **Kulturhus, museum, science centres, regionteatrar** — e.g. Göteborg Kulturhus barn (216), Slottsskogen (202), Universeum, Regionteatern Blekinge Kronoberg (22), Teater Halland (whole Halland).
6. **Permanent places:** kommun lekplats/badplats/utflykt pages, Naturkartan (missing for many small kommuner), Länsstyrelsen naturum.

## Technical notes for scraping (learned in this research)

- **evenemang.se** returns 403 (Cloudflare) everywhere → not used outside Stockholm.
- **Axiell Arena library calendars** and **Svenska kyrkan** calendars render with JavaScript; the agents read counts through their public JSON feeds — the row notes say how. Use the browser for them.
- **Tickster** city pages need the Swedish spelling (`/in/växjö`, `/in/hässleholm`); the ASCII slug shows 0. Most Tickster city pages are adult (concerts, nightlife) — only kept where kids' items exist.
- Several kommun/visit calendars are **Cruncho** iframes or JS lists with JSON endpoints (Höganäs, Ängelholm, Perstorp, Värnamo, vimmerby.com, Visit Gotland) — see notes.
- Some sites answer 403 to a bare user-agent but 200 with a full browser user-agent (filmbyn.se, Kulturparken, bohuslansmuseum.se, naturumtakern.se).
